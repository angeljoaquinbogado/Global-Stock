## OpenAI

Server-only environment variables:

```env
OPENAI_API_KEY=
OPENAI_MODEL=
```

Never expose the key with a `NEXT_PUBLIC_` prefix and never commit it to Git.

Global Stock uses the server route `/api/intelligence`. The browser never receives the OpenAI key.

## Connector security

Required in production:

```env
GLOBAL_STOCK_CONNECTOR_SECRET=
```

Use a random secret with at least 32 characters. It encrypts verified connector sessions stored in HttpOnly cookies.

A public store URL is only used for detection. It never grants permission to read private data or change stock.

The custom Global Stock connector is considered verified only after the remote store returns an authorized token and required scopes such as:

- `catalog:read`
- `inventory:read`
- `inventory:write` when stock updates are allowed

## Ecommerce providers

The app UI distinguishes implemented connectors from providers that still require official app credentials.

Provider credentials belong only on the server:

```env
SHOPIFY_CLIENT_ID=
SHOPIFY_CLIENT_SECRET=

TIENDANUBE_APP_ID=
TIENDANUBE_CLIENT_SECRET=

MERCADOLIBRE_CLIENT_ID=
MERCADOLIBRE_CLIENT_SECRET=
```

WooCommerce uses credentials generated by the store owner and must be handled server-side.

Do not mark a provider as production-ready until its authorization flow, callback validation, token storage, catalog import, stock writeback and revocation flow have all been tested against the provider's current official documentation.
